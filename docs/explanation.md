# Как устроена система — для руководителя

**Как устроена.** Система состоит из двух частей: сайта, который сотрудник открывает в браузере, и базы данных в облачном сервисе Supabase, где хранятся объекты, задачи и история. Сайт только показывает данные и кнопки. Решает, что можно и что нельзя, сама база. Для каждого запроса она знает, кто вошёл, и проверяет его права. Поэтому, даже если обойти сайт и обратиться к базе напрямую, база всё равно откажет в запрещённом действии.

**Как защищены данные.**

- Войти можно только по email и паролю, которые выдал администратор. Зарегистрироваться самому нельзя. Роль («постановщик» или «исполнитель») тоже назначает администратор, сотрудник поменять её себе не может.
- Каждому человеку база отдаёт только то, что ему положено. Постановщик видит всё. Исполнитель видит свои задачи и только те объекты, где у него есть задачи. Чужую задачу он не откроет даже по прямой ссылке.
- Статусы меняются строго по таблице из задания, и база проверяет, кто нажимает кнопку и в каком статусе задача. Вернуть работу на доработку без комментария нельзя.
- Каждую смену статуса база записывает в историю сама: кто, когда, из какого статуса в какой, с каким комментарием. Записи делает база, а не сайт, поэтому подделать их нельзя. Исправить или стереть запись не может ни один пользователь, включая постановщика.
- Удаление ничего не стирает, а только прячет. Удалённая задача пропадает из списков, но она сама и её история остаются в базе, например на случай спора.
- Главный ключ от базы есть только у администратора. На сайт и в код на GitHub он не попадает.

**Чего не может исполнитель:** видеть чужие задачи и объекты, где у него нет задач; создавать, редактировать и удалять задачи и объекты; назначать исполнителей; принимать работу или возвращать её на доработку; перескакивать через статусы, например сразу из «Новая» в «На проверке»; менять историю; менять себе роль.

**Как проверено.** В репозитории есть проверочная программа. Она заходит под каждым тестовым пользователем и обращается к базе напрямую, без сайта. Программа пробует 45 действий, в основном запрещённых. Все запрещённые база отклоняет, разрешённые проходят.
